# Language module

Language preferences are separate from project data. Users can switch between English and Simplified Chinese. The choice is saved under `code-cemetery.locale` in local storage; switching languages does not rewrite stored project records.

## Boundaries

- `src/i18n/translate.ts`: pure translation and placeholder interpolation, shared by the interface and server.
- `src/i18n/react.tsx`: language context, switching, document title, and language attributes.
- `src/i18n/*.en.ts`: English catalogs grouped by feature.
- `src/i18n/content.ts`: display copies of fictional demo projects.
- `EpitaphPlugin.generate(project, style, variant, locale)`: creates new epitaphs in the selected language.
- `ExporterPlugin.export({ ..., locale })`: renders yearbook labels and writing in the selected language.

The optional fifth argument to `classifyProjects` accepts the locale; the existing fourth date argument is unchanged. New projects without an epitaph receive writing in the selected language. Omitting the locale preserves the original Chinese defaults.

## Preserve the user's writing

Switching language translates interface labels, system messages, untouched demo content, and poster labels. Real repository descriptions, custom epitaphs, causes of death, and owner names keep their original text.

Existing epitaphs are not silently replaced. Users can open a project, request a new epitaph in the current language, and save it explicitly. Demo fields are compared individually with their original values, so edited fields remain as written.

The default anonymous owner label is localized for export. A custom owner name is preserved.

## Posters

English text wraps at word boundaries where possible. Oversized identifiers wrap by grapheme, preserving emoji and combining characters. Titles shrink to fit; card heights follow measured text. Language changes do not affect year filtering, ordering, dates, or commit counts.

## Add a language

Extend the `Locale` type, catalogs, switcher, and normalization rules. Add translations for demo display copies, epitaph templates, and poster labels. Keep complete sentences with placeholders such as `{name}` so each language can choose its own word order.

Run `npm test` to check translation coverage, placeholder preservation, custom-content preservation, templates, unknown commit counts, and English poster drawing.
