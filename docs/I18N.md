# 中英文模块

语言偏好与项目数据分离。用户可在界面切换简体中文和英文；偏好保存在浏览器的 `code-cemetery.locale`，不会批量改写 `.data/state.json` 中的项目内容。

## 模块边界

- `src/i18n/translate.ts`：纯文本翻译与插值，供界面和服务端使用。
- `src/i18n/react.tsx`：语言上下文、切换与页面语言标记。
- `src/i18n/*.en.ts`：按界面区域组织的英文文案。
- `src/i18n/content.ts`：示例数据的展示翻译，保留名称、ID、时间、状态、献花和自定义文字。
- `EpitaphPlugin.generate(project, style, variant, locale)`：按所选语言生成新的墓志铭，省略语言时保持原来的中文行为。
- `ExporterPlugin.export({ ..., locale })`：按所选语言生成年度长图，省略语言时仍输出中文。

`classifyProjects` 的第五个可选参数接收语言；已有第四个日期参数保持不变。扫描后只为没有墓志铭的新项目生成当前语言的文案。

## 内容保留规则

切换语言会翻译界面、系统提示、未改动的示例文案和长图标签。真实仓库的描述、用户输入的墓志铭、趣味死因和墓园主人名称保持原文。已保存的中文墓志铭不会被静默替换；切到英文后，可打开详情使用“换一句”生成英文，再保存。

默认匿名主人称呼只在导出中按语言显示。自定义名称不翻译。示例项目的每个字段单独与原始示例比较；修改过的字段继续显示用户的版本。

## 长图排版

英文长图优先按单词换行，过长的单个标识符按字素断行，避免拆坏 emoji 和组合字符。标题按可用宽度缩小，卡片仍根据实际文字高度计算。语言不影响年度筛选、项目顺序或真实提交数据。

## 扩展语言

新增语言时扩展 `Locale` 类型、对应文案目录、语言选择器与解析规则，并为示例展示、墓志铭模板、长图标签补齐翻译。翻译函数的 `{name}` 插值保留完整句子结构，避免用中文语序拼接英文片段。

运行 `npm.cmd test` 验证示例内容保留、英文模板、未知提交数、中文默认兼容性和英文长图绘制。
